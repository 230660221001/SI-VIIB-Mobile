# Aplikasi Akademik PKBM Al Qosimmiyah

## Deskripsi Singkat

Aplikasi Akademik PKBM Al Qosimmiyah merupakan aplikasi berbasis Flutter yang dirancang untuk memudahkan warga belajar dalam mengakses informasi akademik secara praktis melalui perangkat mobile. Aplikasi ini menyediakan beberapa fitur utama, yaitu melihat nilai akademik, mencari detail nilai berdasarkan mata pelajaran, melihat jadwal pelajaran, serta mengetahui jadwal ujian. Dengan adanya aplikasi ini, warga belajar dapat memperoleh informasi akademik dengan lebih mudah, cepat, dan terorganisir tanpa harus mencari informasi secara terpisah.

## Refleksi

Menjaga konsistensi antara diagram alur navigasi, implementasi kode, dan catatan keputusan navigasi. Hal tersebut menjadi tantangan karena setiap route, perpindahan data antarhalaman, validasi formulir, dan feedback yang ditampilkan harus menggambarkan alur aplikasi yang sama. Selain itu, saya juga perlu memastikan bahwa fitur pencarian nilai dapat berjalan sesuai dengan data mata pelajaran yang tersedia. Saya mengatasinya dengan mencocokkan dokumentasi dengan kode program serta melakukan pengujian secara langsung pada setiap halaman dan fitur aplikasi. Melalui pengerjaan tugas ini, saya menjadi lebih memahami penggunaan navigasi pada Flutter, pengiriman data antarhalaman, dan penerapan validasi formulir.
