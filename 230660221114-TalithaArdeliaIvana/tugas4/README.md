## 1. Deskripsi Tugas

Tugas 4 ini bertujuan untuk menganalisis kebutuhan pengguna dan merancang user flow pada aplikasi Akademik PKBM Al Qosimmiyah. Aplikasi ini dirancang untuk memudahkan peserta didik dalam mengakses informasi nilai akademik, jadwal pelajaran, dan jadwal ujian melalui perangkat mobile. Kegiatan yang dilakukan meliputi identifikasi pengguna melalui user persona, penyusunan kebutuhan fungsional dan nonfungsional, penentuan prioritas fitur menggunakan metode MoSCoW, serta perancangan diagram user flow untuk menggambarkan alur penggunaan aplikasi dari awal hingga tujuan tercapai.

## 2. Refleksi

Bagian yang paling sulit bagi saya adalah menentukan prioritas fitur karena setiap fitur memiliki tingkat kepentingan yang berbeda bagi pengguna. Saya juga perlu memastikan bahwa kebutuhan fungsional dapat dipahami dan diuji, serta sesuai dengan tujuan aplikasi Akademik PKBM Al Qosimmiyah. Dalam merancang user flow, saya belajar bahwa setiap titik keputusan harus memiliki cabang berhasil dan gagal agar alur penggunaan aplikasi lebih jelas dan mudah dipahami.
