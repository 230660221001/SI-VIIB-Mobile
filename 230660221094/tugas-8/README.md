## Deskripsi

Folder ini berisi dokumen pengumpulan Ujian Tengah Semester (UTS) mata kuliah Pemrograman Aplikasi Bergerak. Pengumpulan mencakup tes konsep dan laporan evaluasi perkembangan proyek aplikasi SIPUSKAM yang telah dikerjakan secara bertahap mulai dari Tugas 4 hingga Tugas 7.

Proyek SIPUSKAM merupakan aplikasi mobile yang dikembangkan untuk membantu mahasiswa memperoleh informasi mengenai koleksi buku perpustakaan serta mendukung petugas dalam mengelola data buku. Pengembangan aplikasi dilakukan menggunakan framework Flutter dan bahasa pemrograman Dart.
