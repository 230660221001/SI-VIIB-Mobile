# Tugas 4: Dokumen Kebutuhan dan User Flow — [Nama Anda] ([NIM])

Dokumen ini berisi analisis kebutuhan fungsional/nonfungsional, prioritas MoSCoW, user flow, dan pemetaan widget antarmuka untuk aplikasi pencatatan keuangan **CatatUang**.

## Refleksi

Bagian analisis yang paling sulit ditetapkan adalah menentukan batasan prioritas MoSCoW agar kategori Must have tidak melebihi 5 fitur. Hal ini cukup menantang karena banyak fitur yang terlihat penting bagi aplikasi keuangan, sehingga saya harus benar-benar memilah mana fitur inti (_core flow_) pencatatan dan mana fitur pendukung analisis. Selain itu, merancang user flow dengan minimal dua titik keputusan beserta penanganan cabang gagalnya membutuhkan kecermatan alur interaksi pengguna.
