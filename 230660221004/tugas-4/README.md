Deskripsi Singkat Tugas

Tugas ini menganalisis kebutuhan aplikasi PresentGo dan merancang satu user flow utama, yaitu Karyawan melakukan absen masuk dengan pengecekan jaringan, lokasi, dan verifikasi biometrik. Hasilnya berupa dua persona (Karyawan dan Admin HRD), delapan kebutuhan fungsional, dua kebutuhan nonfungsional terukur, prioritas MoSCoW, diagram user flow dengan cabang gagal, dan pemetaan kebutuhan ke halaman serta widget.
