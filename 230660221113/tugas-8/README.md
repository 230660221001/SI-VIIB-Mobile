## Deskripsi Proyek

**FasKampus** merupakan aplikasi mobile berbasis Flutter dan Dart yang dirancang untuk mempermudah mahasiswa serta organisasi kampus dalam mengajukan peminjaman fasilitas kampus.

Aplikasi ini dibuat untuk membantu mengatasi proses peminjaman fasilitas yang sebelumnya masih dilakukan secara manual. Melalui FasKampus, pengguna dapat melihat daftar fasilitas, mengisi formulir peminjaman, serta mengelola data pengajuan.

Fasilitas yang direncanakan dalam aplikasi meliputi aula kampus, ruang kelas, laboratorium, proyektor, sound system, mikrofon, meja, dan fasilitas pendukung lainnya.
