# Tugas 4 — Analisis Kebutuhan dan User Flow FasKampus

## Deskripsi

FasKampus merupakan rancangan aplikasi mobile untuk membantu mahasiswa mencari informasi fasilitas kampus dan mengajukan peminjaman fasilitas. Aplikasi ini dirancang agar mahasiswa dapat memilih fasilitas, mengisi jadwal dan tujuan peminjaman, memeriksa benturan jadwal, serta memantau status pengajuan.

Tugas ini berisi dokumentasi kebutuhan aplikasi dan diagram alur pengguna sebagai dasar perancangan antarmuka.

## Daftar File

- `dokumen-kebutuhan.md` — berisi deskripsi aplikasi, persona pengguna, kebutuhan fungsional dan nonfungsional, prioritas fitur, serta pemetaan kebutuhan ke antarmuka.
- `user-flow.mmd` — berisi kode Mermaid untuk menggambarkan alur mahasiswa saat mengajukan peminjaman fasilitas.
- `user-flow.png` — berisi hasil ekspor diagram user flow dalam format gambar.

## Alur Pengguna

Alur dimulai ketika mahasiswa membuka FasKampus, melihat daftar fasilitas, dan memilih fasilitas yang dibutuhkan. Mahasiswa kemudian mengisi tanggal, waktu, dan tujuan peminjaman, lalu sistem memeriksa kelengkapan data dan benturan jadwal. Jika jadwal tersedia, pengajuan dikirim dan statusnya ditampilkan sebagai **Menunggu Persetujuan**.

## Refleksi

1. Bagian yang paling sulit bagi saya adalah menentukan kebutuhan fungsional karena setiap fitur harus sesuai dengan kebutuhan mahasiswa dan admin fasilitas.
2. Saya belajar bahwa user flow harus menunjukkan pilihan pengguna beserta jalur alternatifnya agar alur aplikasi mudah dipahami.
3. Melalui tugas ini, saya memahami bahwa analisis kebutuhan dan user flow penting dilakukan sebelum merancang antarmuka aplikasi.
