# Tugas 4 — Analisis Kebutuhan Aplikasi Bergerak

## Nama Aplikasi
**Mantra Attendance**

## Deskripsi Singkat

Mantra Attendance merupakan rancangan aplikasi mobile untuk membantu proses pencatatan dan pemantauan kehadiran karyawan pada PT Mantra Group. Aplikasi dirancang dengan dua peran utama, yaitu karyawan dan admin, dengan fungsi utama berupa login, melihat status kehadiran, check-in, check-out, melihat riwayat absensi, serta pemantauan data oleh admin. Perancangan kebutuhan mencakup user persona, functional requirement, non-functional requirement, prioritas MoSCoW, user flow, dan pemetaan kebutuhan terhadap halaman serta widget yang akan digunakan pada tahap implementasi aplikasi.

## Domain Sistem Informasi

Sistem Informasi Absensi Karyawan PT Mantra Group.
