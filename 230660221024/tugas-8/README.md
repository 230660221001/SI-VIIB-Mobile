## Deskripsi Singkat

Folder ini berisi pengumpulan Ujian Tengah Semester (UTS) untuk Milestone M4. Pengumpulan terdiri dari dua komponen utama: **Tes Konsep** (menjawab 10 soal esai terkait teori CPMK 1-3) dan **Evaluasi Progress Project** (laporan kemajuan aplikasi Absensi Organisasi Mahasiswa dari Tugas 1 hingga Tugas 7).

## Daftar Artefak UTS (Sesuai Bagian 6.1)

1. **Tes Konsep:** File `tes-konsep-uts.md` (berisi jawaban Soal 1-10).
2. **Laporan Progress:** File `laporan-progress-uts.md` (berisi ringkasan eksekutif, matriks kebutuhan, kendala, dan refleksi).
3. **Artefak Project (Tugas 1-7):**
   - **M1 (Kebutuhan):** Tersedia di folder `tugas-1/` dan `tugas-4/`.
   - **M2 (UI/UX & Navigasi):** Tersedia di folder `tugas-5/` (Wireframe) dan `tugas-6/` (Navigation flow & Form).
   - **M3 (MVP Awal):** Tersedia di folder `tugas-7/` (File `crud-lokal.dart`).

## Cara Menjalankan Aplikasi MVP

Aplikasi MVP final saat ini berada di dalam file `tugas-7/crud-lokal.dart`. 
Untuk menjalankannya:
1. Buka project Flutter (`aplikasi-pab`).
2. Salin seluruh isi file `tugas-7/crud-lokal.dart` ke dalam `lib/main.dart`.
3. Jalankan perintah `flutter run -d chrome` di terminal.
