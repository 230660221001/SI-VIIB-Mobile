# Tugas 4: Dokumen Kebutuhan dan User Flow

Repository ini berisi dokumen analisis kebutuhan fungsional dan nonfungsional, user persona, prioritas fitur berbasis MoSCoW, pemetaan kebutuhan ke antarmuka widget Flutter, serta diagram user flow untuk aplikasi **LabSpace**.

## Refleksi
Bagian analisis yang paling sulit ditetapkan adalah penyusunan alur **user flow** dan penetapan **prioritas MoSCoW**. Hal ini dikarenakan saya harus memastikan setiap titik keputusan pada alur memiliki cabang penanganan gagal yang logis dan tidak buntu. Selain itu, membatasi fitur *Must Have* maksimal 5 fitur menuntut pertimbangan ketat agar hanya fungsi paling krusial bagi persona yang diprioritaskan pada tahap MVP.
