# Deskripsi singkat tugas

Tugas 4 ini membahas analisis kebutuhan aplikasi Lapor Fasilitas FTI, yaitu aplikasi mobile yang dirancang untuk membantu mahasiswa dan dosen melaporkan kerusakan fasilitas fakultas serta membantu Petugas Fasilitas Fakultas memantau dan menindaklanjuti laporan. Dokumen ini mencakup deskripsi aplikasi, user persona, kebutuhan fungsional dan nonfungsional, prioritas fitur menggunakan metode MoSCoW, serta user flow untuk proses pengiriman laporan. 

## Refleksi

Bagian yang paling sulit dalam analisis kebutuhan adalah menentukan prioritas fitur karena setiap fitur memiliki manfaat, tetapi tidak semuanya harus tersedia pada tahap awal pengembangan aplikasi. Saya juga mengalami kesulitan dalam menyusun user flow karena perlu memastikan bahwa setiap langkah dan keputusan memiliki alur lanjutan, termasuk ketika terjadi kegagalan. Dari proses ini, saya belajar bahwa penentuan prioritas membantu membatasi ruang lingkup pengembangan, sedangkan user flow membantu menggambarkan proses penggunaan aplikasi secara lebih terstruktur.
