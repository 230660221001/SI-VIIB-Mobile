# Tugas 7 — MVP Awal dengan Data Lokal

## Deskripsi Singkat

Tugas 7 merupakan tahap implementasi awal aplikasi Lapor Fasilitas FTI dalam bentuk Minimum Viable Product (MVP) menggunakan Flutter dan data lokal. Pada tugas ini dilakukan perancangan model data, implementasi operasi CRUD (Create, Read, Update, Delete), serta pengujian pengelolaan data melalui antarmuka aplikasi. Hasil pengerjaan dilengkapi dengan dokumentasi model data, keputusan perancangan, dan tangkapan layar sebagai bukti implementasi.

## Refleksi

Bagian yang paling sulit dipertahankan konsistensinya adalah hubungan antara model data dan operasi CRUD dengan kebutuhan fungsional pada Tugas 4. Kesulitan tersebut muncul karena setiap field dan operasi harus memiliki fungsi yang sesuai dengan alur penggunaan Pelapor dan Petugas, termasuk aturan perubahan serta penghapusan laporan berdasarkan statusnya. Oleh karena itu, diperlukan ketelitian dalam menentukan struktur model data dan aturan CRUD agar implementasi aplikasi tetap sesuai dengan kebutuhan yang telah ditentukan.
