# Tugas 5 — UI/UX Mobile Lapor Fasilitas FTI

## Deskripsi

Tugas ini mengimplementasikan rancangan UI/UX aplikasi Lapor Fasilitas FTI menggunakan Flutter dan Material 3. Halaman utama menampilkan ringkasan laporan, daftar laporan kerusakan beserta statusnya, serta tombol untuk membuat laporan. Implementasi menggunakan data contoh dan menyediakan tampilan kosong ketika belum ada laporan.

## Refleksi

Bagian yang paling sulit bagi saya adalah menjaga konsistensi antara wireframe dan kode Flutter. Hal ini karena susunan dan ukuran komponen yang terlihat pada wireframe perlu disesuaikan dengan widget Flutter agar tampilannya tetap sesuai dengan rancangan awal. Saya belajar bahwa implementasi UI perlu diperiksa kembali melalui hasil aplikasi yang dijalankan agar perbedaan antara rancangan dan kode dapat diketahui dan diperbaiki.
